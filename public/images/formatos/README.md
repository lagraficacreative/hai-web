# Imágenes de la sección «Un mismo HAI, todos los formatos» (index.html)

Coloca cada foto con el nombre exacto y quedará puesta sola en la portada.
Formato recomendado: **JPG, 16:10** (p. ej. 800×500 px), pesada al mínimo (< 200 KB).

| Archivo | Dispositivo |
|---|---|
| `web.jpg`          | 🌐 Página web |
| `app.jpg`          | 📱 Aplicación móvil |
| `videollamada.jpg` | 📹 Videollamada |
| `ventilador.jpg`   | 🌀 Ventilador holográfico |
| `cabina.jpg`       | 🔮 Cabina holográfica |
| `pantalla.jpg`     | 🪟 Pantalla transparente |
| `quiosco.jpg`      | 🖥️ Quioscos y pantallas táctiles |

Si algún archivo no existe todavía, verás un gradiente azul-turquesa como placeholder
(nada roto). En cuanto lo subas, el navegador lo enseñará sin más cambios.
